# 关键运行流程

## 1. 创建演示会话

- 参与者：匿名浏览器用户。
- 前置条件：场景只能是 `default`、`rain` 或 `moving`；浏览器坐标为可选字段，必须由页面上的用户点击触发权限请求。
- 流程：浏览器 `POST /api/cabin/session` → Python/FastAPI 来源窗口限流 → Pydantic 场景及 WGS84 范围校验 → 服务端生成随机 UUID → 返回含位置来源与精度的模拟状态。
- 拒绝路径：非法场景或坐标返回 400；超过窗口限制返回 429；用户拒绝定位时前端继续使用模拟位置。
- 状态变化：服务端内存中新增 30 分钟有效会话。
- 边界：会话 ID 只隔离演示状态，不代表认证或所有权。

## 2. DeepSeek 多轮任务执行

- 参与者：匿名用户、Python/FastAPI 服务端、DeepSeek、服务端工具执行器。
- 前置条件：有效会话 ID；文本 1–500 字；最多 10 条历史；服务端配置 DeepSeek 密钥。
- 流程：
  1. 服务端校验请求并从会话读取可信车辆状态。
  2. 文本和有限历史发送至 DeepSeek；长期密钥不进入浏览器。
  3. 模型返回工具调用；服务端对每个参数再次进行 Pydantic 严格校验。
  4. 执行器核对读取前置条件、安全约束、导航授权和候选目的地。
  5. 工具结果回传模型，最多循环 6 轮。
  6. 返回前检查“已完成”表述是否有成功副作用作为依据。
- 拒绝路径：非法请求 400；过期会话 404；限流 429；供应商失败 502；超过轮次停止执行。
- 状态变化：只有通过执行器校验的写工具才能更新模拟状态。
- 外部副作用：产生 DeepSeek API Token 消耗。

## 3. 高速天窗确认

- 参与者：驾驶者、服务端确认状态机、工具执行器。
- 前置条件：车速不低于 80 km/h、无降雨阻止、用户请求开启天窗。
- 流程：首次 `control_sunroof` 被阻止 → 会话保存目标开度和 2 分钟 TTL → 用户下一轮明确确认 → 服务端取出一次性动作 → 重新执行天气/车速硬规则 → 更新天窗。
- 授权判定：只接受完整、明确的确认回复；任何取消词优先；疑问或话题切换不视为确认。
- 拒绝路径：取消、模糊回复、确认过期或降雨均不执行。
- 状态变化：确认一次性消费；执行成功后更新天窗和遮阳帘模拟状态。

## 4. 补能搜索与导航

- 前置条件：当前请求先成功读取车辆状态。
- 流程：读取电量/续航/位置来源/路线 → 按最大绕行过滤含坐标的候选站 → 解释候选 → 用户明确要求导航时生成距离、ETA 和路线折线 → Agent Lab 可视化路线。
- 硬约束：没有明确导航意图、没有搜索结果或目的地不在本轮候选中时，`start_navigation` 被阻止。
- 状态变化：成功后更新会话中的目的地、路线距离、ETA 与折线点。
- 数据边界：浏览器坐标来自用户授权；固定充电站目录与其路线是 CabinGuard 演示沙箱。普通地点由 Nominatim 检索，道路路线由 OSRM 计算，属于真实公共道路数据但没有实时路况或 SLA。

## 5. 普通地点检索与真实道路导航

- 触发：用户明确提出“导航到某地”或提交地点检索。
- 流程：`get_vehicle_state` → `search_places` → 候选写入会话 → `plan_navigation` → OSRM 道路结果 → 地图、步骤、备选路线和到达电量。
- 硬约束：只能使用本会话候选 ID；浏览器真实起点需要外部算路同意；外部失败时禁止返回模拟成功。
- 隐私：候选和路线坐标留在服务端状态并返回同一浏览器，不进入大模型工具回执。

## 5. Reliability Lab

- 参与者：产品/研发评审者、评测页或 Python CLI、真实 Agent API、Python 评分器。
- 流程：按 Base / Hallucination / Disambiguation 选择共享任务 → 每试次创建独立会话 → 在同一会话执行多轮输入 → 五维评分 → 聚合试次通过率、Pass^k、Pass@k → 导出版本化 JSON。
- 外部副作用：产生 API 成本；因此不是默认 CI 门禁。
- 成本护栏：全量 15 个任务重复 3 次必须显式解锁；面试演示默认按单一类型运行。
- CI 门禁：运行 Ruff、66 条 Python 测试、39 条 TypeScript 兼容测试，以及前端 lint、类型检查和生产构建；均不依赖外部模型。

## 6. Agent Lab 浏览器语音与定位

- 语音输入：用户点击麦克风后，浏览器用 `SpeechRecognition` 将中文语音转成文字；文字先进入输入框，用户确认发送后才调用 Agent。
- 语音输出：用户可以开关 `SpeechSynthesis` 回复播报。
- 定位：用户点击定位按钮后，页面调用 `navigator.geolocation.getCurrentPosition`；成功后用坐标新建会话，失败则保留模拟位置。
- 权限边界：语音识别与定位能力取决于浏览器、系统权限和安全上下文；语音识别可能由浏览器厂商的在线服务处理。精确定位只保留在本地服务端会话与页面响应中，不写入发送给大模型的工具回执。

## 7. Realtime 语音

- 参与者：浏览器、OpenAI Realtime API。
- 前置条件：服务端配置具有 Realtime 权限的 OpenAI 密钥。
- 边界：服务端只签发短期 client secret；Realtime 工具仍使用独立客户端模拟状态，不能等同于 DeepSeek 服务端安全链路。
