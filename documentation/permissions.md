# 权限与能力矩阵

## 当前角色

| 角色 | 身份来源 | 能力 |
| --- | --- | --- |
| 匿名演示用户 | 无账号；持有随机会话 ID | 创建模拟会话、提交有限文本/历史、查看自己的返回状态 |
| DeepSeek 模型 | 服务端调用结果 | 建议工具与参数；不能直接写会话状态 |
| 服务端工具执行器 | 应用内部代码 | 校验并执行模拟状态读写 |
| 评测操作者 | 浏览器用户或 Python CLI 用户 | 选择 15 个共享任务的子集与 1/3 次试次、运行付费模型评测、导出本地 JSON；全量三次需显式解锁 |

## 资源 × 操作矩阵

| 资源/操作 | 匿名用户 | 模型 | 服务端执行器 |
| --- | --- | --- | --- |
| 创建模拟会话 | 允许，受限流与场景校验 | 不允许 | 执行创建 |
| 直接提交车辆状态 | 不允许 | 不允许 | 从服务端会话读取 |
| 读取模拟车况 | 通过 Agent 间接请求 | 可建议读取工具 | 允许 |
| 修改模拟车况 | 不允许直接修改 | 仅可建议写工具 | 校验通过后允许 |
| 高速天窗确认 | 通过明确下一轮回复 | 不可自行授予 | 会话状态机判定并一次性消费 |
| 启动补能导航 | 必须明确提出导航 | 可建议 | 同时校验意图、搜索前置和候选目的地 |
| 读取供应商密钥 | 不允许 | 不可见 | 服务端环境变量读取 |

## 明确边界

- 当前没有登录、用户归属、租户隔离、管理员或真实车辆所有权校验。
- 会话 ID 不应被描述为认证 Token；知道 ID 的人可能访问同一模拟会话。
- 没有数据库和行级安全策略；所有会话状态在单进程 Map 中。
- 公开部署前必须增加认证、会话归属、持久化配额和可信代理/IP 配置。
